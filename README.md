# Umer Sohail's academic website

This repository contains the source for [umerssohail.com](https://umerssohail.com/), my academic website.

I am an Economics Ph.D. candidate at the University of Delaware. My research focuses on international trade, applied microeconomics, and development, with a particular interest in how trade policy and institutions affect firms. The site includes my research, teaching, and CV.

## Built with

The site uses [Jekyll](https://jekyllrb.com/) and the [Academic Pages](https://academicpages.github.io/) theme, which is based on [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/).
